About Pagewright

Pagewright is a file-based CMS designed for non-technical users who want the simplicity of WordPress with the clarity of modern static site generators.

How It Works

  1. You write content in markdown files
  2. You describe changes in natural language
  3. Pagewright validates your changes for safety
  4. The compiler builds HTML from your content
  5. You preview before publishing
  6. Your site goes live with one click

Designed for Simplicity

No database to configure. No local development environment. No build toolchain. Everything happens on your hosting server.

Core Principles

Content is Files

All your site content lives in plain markdown files. No database queries, no data migrations, no vendor lock-in.

Themes are Contracts

Themes define what components you can use, what regions are available, and how your content is rendered. Change themes without breaking content.

LLMs are Assistants

The AI helps you edit content but never has full control. Every change is validated, previewable, and reversible.

Safety First

  • Path restrictions prevent access to system files
  • Component validation prevents code injection
  • Changelog system allows instant rollback
  • Preview before publish

WordPress-Inspired

If you've used WordPress, Pagewright will feel familiar:

  • Pages: Like WordPress posts, but in markdown
  • Themes: Switch themes, customize tokens
  • Components: Like WordPress blocks/shortcodes
  • Widgets: Sidebar content areas
  • Menu: Visual menu builder

But unlike WordPress:

  • ✅ No database required
  • ✅ No security updates every week
  • ✅ No plugin compatibility issues
  • ✅ Version control friendly
  • ✅ Runs on the cheapest hosting

Who Is This For?

Pagewright is perfect for:

  • Small business websites
  • Personal portfolios
  • Documentation sites
  • Landing pages
  • Blogs and content sites

If you want WordPress simplicity without WordPress complexity, Pagewright is for you.
